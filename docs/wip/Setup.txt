## MODEL SECTION
- describes overall data 'structures' and general overview of interaction
- ex.
	```yml
		data_file:
			general: # statements regarding the structure of the genereal data files (per survey/data endpoint basis)
				use_mmap: true
				obs_value:
				schema:#
		lookupfile:
			lookup_config: # defines loading strategy (SEE: strategy validation)
		files:
			$FILE_CONFIG_!: # file configuration for file 1 (SEE: lookup_files validation)
			
	```
